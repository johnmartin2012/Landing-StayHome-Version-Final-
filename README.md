# Stay Home Massage Gold Coast — Website

Premium mobile massage therapy website for Stay Home Massage Gold Coast.
Built with HTML, CSS, JavaScript, GSAP and Lenis.

## Tech Stack

- **HTML5** — semantic, accessible markup
- **CSS3** — custom properties, CSS Grid, responsive design
- **Vanilla JavaScript** — zero frameworks
- **GSAP + ScrollTrigger** — scroll animations and parallax
- **Lenis** — smooth scroll
- **Sharp** — image optimisation (build-time, via Node.js)
- **Google Fonts** — Playfair Display + Cormorant Garamond

## Project Structure

```
/
├── index.html          # Single-page site
├── styles.css          # All styles
├── script.js           # Animations & interactions
├── assets/             # Images (PNG originals + WebP optimised)
└── optimize-images.js  # One-time image optimisation script
```

## Features

- One-page conversion-focused layout
- WhatsApp booking CTAs throughout
- Responsive from 320px to 4K
- WebP images with PNG fallback and responsive `srcset`
- Hero parallax, GSAP scroll reveals, stat counters
- FAQ accordion, marquee strip, asymmetric gallery grid
